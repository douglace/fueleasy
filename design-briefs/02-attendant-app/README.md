# App Pompiste Fusy — Brief de conception

## Mission

Permettre à un pompiste de retrouver rapidement les demandes de sa station, vérifier code, chauffeur, entreprise, montant et carburant, puis valider ou refuser sans modifier les données.

## Plateforme

Flutter Android prioritaire. Usage debout, en station, au soleil, avec interruptions fréquentes et réseau irrégulier.

## Ordre de lecture

Lire les quatre documents de [`../00-shared`](../00-shared/), puis les fichiers numérotés de ce dossier et terminer par [`CLAUDE-DESIGN-PROMPT.md`](CLAUDE-DESIGN-PROMPT.md).

## Résultat attendu

Une app Android minimaliste couvrant connexion, file d'attente, code court, validation/refus, attente de confirmation chauffeur et historique du jour.
