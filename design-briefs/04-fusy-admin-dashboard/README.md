# Dashboard Admin Fusy — Brief de conception

## Mission

Permettre à l'équipe Fusy d'onboarder et superviser entreprises, stations et pompistes, créditer manuellement les comptes, gérer les QR et stations autorisées, auditer les actions et préparer les reversements du pilote.

## Plateforme

Web desktop responsive interne. Cible 1440 px, utilisable à partir de 1280 px.

## Ordre de lecture

Lire les quatre documents de [`../00-shared`](../00-shared/), les fichiers numérotés de ce dossier, puis [`CLAUDE-DESIGN-PROMPT.md`](CLAUDE-DESIGN-PROMPT.md).

## Résultat attendu

Une interface interne dense mais claire, avec statuts globaux visibles, actions sensibles confirmées et audit facilement consultable.
