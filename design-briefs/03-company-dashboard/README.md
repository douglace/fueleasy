# Dashboard Entreprise Fusy — Brief de conception

## Mission

Permettre à une entreprise cliente de voir son solde réel, gérer ses chauffeurs et budgets, consulter les stations autorisées, analyser les transactions et produire des exports simples.

## Plateforme

Web desktop responsive. Cible principale 1440 px, utilisable dès 1280 px et consultable sur tablette.

## Ordre de lecture

Lire les quatre documents de [`../00-shared`](../00-shared/), les fichiers numérotés de ce dossier, puis [`CLAUDE-DESIGN-PROMPT.md`](CLAUDE-DESIGN-PROMPT.md).

## Résultat attendu

Un dashboard simple à apprendre, distinguant clairement solde réel et budgets d'autorisation, avec vues Chauffeurs, Stations, Transactions et Rapports.
